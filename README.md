# React + Vite

## Run the API (terminal 1)
    cd backend/server
    npm start          # http://localhost:3001/api/items

## Run the React app (terminal 2)
    cd backend/client
    npm install
    npm run dev        # open the URL Vite prints, usually http://localhost:5173

## Run the React app (terminal 3)
    cd backend/server
    npm start
